
🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript. Play with two players, take turns placing O and X, and see who wins!

✨ Features

- Interactive 3×3 Tic Tac Toe game board.
- Two-player gameplay (O and X).
- Automatic winner detection.
- Winning pattern checking.
- Winner announcement message.
- Confetti fireworks animation when a player wins.
- Reset Game and New Game options.
- Responsive and user-friendly interface.

---

🛠️ Technologies Used

- HTML5 – Structure of the game.
- CSS3 – Styling and layout.
- JavaScript – Game logic and winner detection.
- Canvas Confetti – Celebration animation.

💻 How to Run Locally

1. Clone this repository:
   
   git clone https://github.com/Pragya158/Tic-Tac-Toe-Game.git


2. Open the project folder.

3. Open "index.html" in your browser.

4. Start playing Tic Tac Toe!

---

🎯 How to Play

1. Player O starts the game.
2. Players take turns selecting empty boxes.
3. The first player to get three matching symbols in a row, column, or diagonal wins.
4. Click Reset or New Game to play again.
